Install App

These steps install the current web app. The planned native iOS and Android apps are not yet available.

Safari

  1. Open rhaag71.github.io/klondike/ in Safari.
  2. Tap Share. On some Safari layouts, tap Page Menu, then Share.
  3. Select Add to Home Screen.
  4. Enable Open as Web App, if presented.
  5. Tap Add.

The game will appear on the Home Screen and launch as an app.

Google Chrome

  1. Open rhaag71.github.io/klondike/ in Chrome.
  2. Open the three-dot menu.
  3. Select Install and create shortcut, Install app, or Add to Home screen. The label varies by Chrome version.
  4. Confirm installation.

The game can then be launched from the Home Screen or app launcher.

After the initial load and caching complete, DIM8 Solitaire supports offline play.

Absurdly Accurate Clock

A GPS/PPS-disciplined embedded clock built around the Raspberry Pi Pico 2. The firmware maintains an authoritative UTC timebase independent of the display, drives a Posiflex serial VFD through an RS-232 interface, and provides a defined interface for an ESP32 network-time appliance. Designed as a timing system first and a clock display second.

AAC Time Bridge

An ESP32 network time appliance for the Absurdly Accurate Clock. It consumes qualified UTC from the RP2350-based clock over the AAC SPI/TIME_SYNC interface and serves it to the local network as NTP, while providing a local WebUI for source qualification, network state, timing diagnostics, and appliance management.
